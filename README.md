# Vision-Assistive Edge AI Application

Welcome to the complete source code for our Flutter Edge AI workshop project!

This branch contains the fully implemented codebase. However, the app will not run immediately after cloning.

## ⚠️ Required Setup Before Running

To keep sensitive data secure and give you hands-on experience with cloud integrations, specific configuration files and API keys are not included in this repository.

Before you can build and run this app, you must configure your own environment by adding:

1. Your own google-services.json file (for Firebase).
2. Your OAuth client_id (for Google Sign-In, Calendar, and Gmail integrations).
3. Your Hugging Face ID / Access Token (for model access).

## 📖 Step-by-Step Setup Guide

We have prepared a comprehensive, step-by-step tutorial on how to generate these credentials and place them correctly in your project.

Please follow the instructions on our Notion page to get your app running:

👉 [GCP & Firebase Setup Instructions](https://app.notion.com/p/GCP-Firebase-Setup-3e8afd693fac805cb658ce691dbd4b93?source=copy_link)

Once you have completed the guide and added your keys, you can run the app on your physical device or emulator. Happy coding!
